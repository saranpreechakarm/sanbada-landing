# คู่มือส่งต่อระบบจัดการโปรเจกต์และวิดีโอ Sanbada

## สำหรับผู้ดูแลเว็บไซต์

เข้าเว็บไซต์ตาม URL ที่ใช้งาน แล้วต่อท้าย `/admin/login` ด้วยบัญชีส่วนตัวของคุณ

เมนู **คู่มือการใช้งาน** ในแอดมินมีขั้นตอนทั้งหมดและพิมพ์ออกมาได้

- **โปรเจกต์:** เพิ่มและแก้ไขชื่อ หมวดคอนโด/วิลล่า ทำเล ราคา จำนวนห้องนอน รายละเอียดภาษาอังกฤษและรัสเซีย รูป และโบรชัวร์ PDF
- **โครงการใหม่:** ติ๊กเพื่อแสดงใน New Projects และติดป้ายบนการ์ด ไม่ได้เปิดอัตโนมัติให้โครงการเดิมเพราะยังไม่ทราบวันเปิดตัวจริง
- **โครงการแนะนำ:** ติ๊กเพื่อจัดขึ้นก่อนในหมวดเดียวกัน เลขลำดับน้อยแสดงก่อน
- **ฉบับร่าง:** ซ่อนจากทุกส่วนของหน้าเว็บ ใช้เมื่อต้องการพักการขายหรือเตรียมข้อมูล
- **ถังขยะ:** โปรเจกต์ที่ลบกู้คืนได้จากตัวกรองถังขยะ โดยจะกลับมาเป็นฉบับร่าง
- **รูปภาพ:** JPG/PNG/WebP ไม่เกิน 8 MB ต่อรูป สูงสุด 30 รูป ลากรูปเพื่อจัดเรียงรวมรูปเดิมและรูปใหม่ได้ ใช้ลูกศรเลื่อนลำดับบนมือถือ หรือกด “ตั้งเป็นปก” รูปแรกในแกลเลอรีจะเป็นรูปปก กดบันทึกโปรเจกต์เพื่อใช้ลำดับใหม่
- **PDF:** ไม่เกิน 20 MB ลูกค้ารับลิงก์หลังส่งแบบฟอร์มสนใจ โปรเจกต์ที่ซ่อนหรือลบจะดาวน์โหลดไม่ได้
- **วิดีโอ:** วางลิงก์ YouTube หรือ Vimeo แบบ HTTPS กรอกชื่อทั้ง 2 ภาษา และเลือกผูกกับโปรเจกต์ได้ เลือกสัดส่วนคลิป 16:9, 9:16, 1:1 หรือ 4:5 ให้ตรงต้นฉบับได้ การลบวิดีโอเป็นการลบรายการจริง
- **ผู้ดูแลระบบ:** เพิ่มผู้รับช่วงต่อและผู้ดูแลสำรอง ตั้งรหัสผ่านใหม่ให้คนอื่น หรือยกเลิกสิทธิ์ได้ ทุกบัญชีมีสิทธิ์เท่ากัน

เมื่อมีข้อผิดพลาดในการกรอกข้อมูล ต้องเลือกไฟล์รูปและ PDF ใหม่ก่อนส่งอีกครั้ง เบราว์เซอร์ไม่เก็บไฟล์ที่เลือกให้ข้ามคำขอ

หลังส่งต่องาน ให้ผู้รับช่วงต่อทดสอบเพิ่มโปรเจกต์และวิดีโอฉบับร่าง เปลี่ยนรหัสผ่านของตน และยกเลิกสิทธิ์บัญชีที่เลิกใช้งาน

## สำหรับผู้ติดตั้ง / ผู้ดูแลโฮสติ้ง

### เปิดใช้งานบนเครื่องนี้

เปิด MySQL ใน MAMP แล้วดับเบิลคลิก `start-local.cmd` ที่รากโปรเจกต์ โดยใช้ PHP 8.2 ขึ้นไปที่ติดตั้งใน PATH หน้าต่างนี้ต้องเปิดค้างไว้ระหว่างใช้งาน เว็บอยู่ที่ `http://127.0.0.1:8124/ru` และแอดมินที่ `http://127.0.0.1:8124/admin/login` หากเซิร์ฟเวอร์บนพอร์ตนี้เปิดอยู่แล้ว ไม่ต้องเปิดซ้ำ

PHP ของ Apache ใน MAMP เครื่องนี้ตั้งไว้รุ่น 8.0 ซึ่งต่ำกว่าข้อกำหนด Laravel เดิม ตัวเปิด local จึงใช้ PHP 8.4 ที่ติดตั้งในเครื่อง หากต้องการเปิดผ่าน Apache ของ MAMP ให้ผู้ดูแลเครื่องตั้ง PHP เป็น 8.2 ขึ้นไปก่อน

### ติดตั้งบนโฮสติ้ง

ใช้ Laravel/PHP และ MySQL เดิม ไม่ต้องติดตั้งแพ็กเกจใหม่และไม่ต้อง build หน้าแอดมิน รูปเดิมจะเลือกไฟล์ WebP ที่มีอยู่ใน `assets/projects-optimized` โดยอัตโนมัติ

1. สำรองฐานข้อมูลและซอร์สโค้ดเดิมก่อนอัปเดต
2. วางไฟล์ชุดนี้ในโปรเจกต์เดิม โดยเก็บ `.env`, `vendor`, รูปเดิม, ฐานข้อมูล และไฟล์ LINE CRM ไว้
3. ใช้ PHP 8.2 ขึ้นไป พร้อม PDO MySQL, fileinfo และ mbstring
4. ตั้ง `APP_URL` ใน `.env` เป็น URL จริงที่เข้าถึงหน้าเว็บได้ รวม path ก่อน `/ru` หากมี อย่าเพิ่ม `/ru` หรือ `/admin` ท้ายค่านี้
5. ให้ PHP เขียน `public/uploads/content`, `storage` และ `bootstrap/cache` ได้
6. ตั้ง PHP `upload_max_filesize=20M`, `post_max_size=256M`, `max_file_uploads=30` และปรับ request body limit ของเว็บเซิร์ฟเวอร์ให้สอดคล้อง หากตั้งค่าต่ำกว่านี้จะอัปโหลดไฟล์ขนาดสูงสุดที่ฟอร์มระบุไม่ได้
7. รันจากรากโปรเจกต์:

```powershell
php artisan content:install
php artisan optimize:clear
php artisan content:setup-link
```

เปิดลิงก์ที่คำสั่งสุดท้ายแสดงเพื่อสร้างผู้ดูแลคนแรก เลือกรหัสผ่านเองอย่างน้อย 12 ตัวอักษร ลิงก์หมดอายุใน 30 นาทีและใช้ไม่ได้หลังมีผู้ดูแลแล้ว หาก URL สำหรับ local ต่างจาก APP_URL ใช้:

```powershell
php artisan content:setup-link --base-url=http://127.0.0.1:8000
```

หากอีเมลนั้นมีบัญชีเดิมใน users แล้ว ต้องใช้อีเมลใหม่สำหรับการตั้งค่าครั้งแรก ระบบไม่เปลี่ยนสิทธิ์บัญชี LINE CRM เดิมให้อัตโนมัติ

**อย่ารัน `migrate:fresh` กับฐานข้อมูลจริง** และใช้ `content:install` สำหรับฟีเจอร์นี้ เพราะ migration leads เดิมมีคำสั่งสร้างตารางอยู่นอกเมธอด `up()` ตัวติดตั้งนี้เลือกเฉพาะ migration ใหม่ จึงไม่เรียกไฟล์เดิมนั้น

ต้องมีตาราง `users` และ `migrations` ของแอปเดิมก่อนติดตั้ง ตัวติดตั้งเพิ่ม `users.can_manage_content`, ตาราง `projects`, `videos` และแถวล็อกการตั้งค่าครั้งแรกใน `content_admin_setup` โดยไม่เปลี่ยนข้อมูลลูกค้า LINE หรือ leads

นำเข้ารายการโปรเจกต์จากไฟล์เดิมครั้งแรกเท่านั้น รันซ้ำไม่เขียนทับข้อมูลที่แก้แล้วและไม่กู้คืนโปรเจกต์ในถังขยะ วิดีโอจะเริ่มเป็นรายการว่าง รอทีมใส่ลิงก์จริง

การแบ่งหมวดข้อมูลเดิมใช้ชื่อที่ระบุ VILLA เป็นวิลล่า รายการอื่นเริ่มเป็นคอนโด ให้ตรวจหมวดของแต่ละโครงการก่อนเผยแพร่ใช้งานจริง

## สำรองและกู้คืน

เก็บฐานข้อมูลและไฟล์เหล่านี้พร้อมกัน:

- `public/uploads/content` — รูปอัปโหลดจากแอดมิน
- `storage/app/content` — โบรชัวร์อัปโหลด เก็บนอก web root
- `public/assets/projects` และ `public/assets/projects-optimized` — รูป/PDF เดิม
- ซอร์สโค้ดและ `.env` โดยเก็บค่าลับแยกจากเอกสารส่งต่อ

การนำรูปหรือ PDF ออกจากโปรเจกต์ไม่ลบไฟล์จากดิสก์ทันทีเพื่อรองรับการกู้คืน ผู้ดูแลโฮสติ้งค่อยทำความสะอาดไฟล์ที่ไม่ใช้หลังมีข้อมูลสำรองแล้ว

หากผู้ดูแลทุกคนลืมรหัสผ่าน ให้ผู้ดูแลโฮสติ้งตั้งรหัสใหม่ผ่าน Laravel โดยใช้ช่องทางที่ไม่บันทึกรหัสผ่านลงประวัติคำสั่ง ไม่มีรหัสเริ่มต้นหรือบัญชีที่ฝังไว้ในโค้ด

## ขอบเขตและการตรวจสอบ

ระบบนี้ดูแลโปรเจกต์และวิดีโอ รวม New Projects/โครงการแนะนำ ข้อความบริษัท ติดต่อ โปรโมชั่น และส่วนอื่นยังใช้ไฟล์เดิม

ลิงก์ PDF เป็นลิงก์ดาวน์โหลดของโครงการที่เผยแพร่ ไม่ใช่ระบบสมาชิกหรือเอกสารลับ เนื้อหาวิดีโอและสิทธิ์การฝังยังจัดการจาก YouTube/Vimeo

ทดสอบด้วย PHPUnit ที่ใช้ SQLite ชั่วคราว: แยกสิทธิ์แอดมิน/CRM, เข้าสู่ระบบ, ลิงก์ตั้งค่าหมดอายุ, สร้าง/แก้ไข/ถังขยะ/กู้คืน, อัปโหลดและจัดรูป, PDF, วิดีโอ, ฉบับร่าง, หน้า EN/RU, XSS, จัดการผู้ดูแล และ import ซ้ำโดยรักษาข้อมูลเดิม

```powershell
php -d extension=pdo_sqlite -d extension=sqlite3 vendor/phpunit/phpunit/phpunit
```

หากเปิด extension เหล่านี้ใน php.ini แล้ว ใช้ `php artisan test` ได้ตามปกติ ฐานข้อมูลทดสอบเป็น SQLite ในหน่วยความจำ ไม่ใช่ MySQL จริง

## การปรับรูปแบบและสัดส่วนวิดีโอ

มี migration เพิ่ม `videos.aspect_ratio` โดยไม่เปลี่ยนชื่อหรือลิงก์วิดีโอเดิม ลิงก์ YouTube Shorts เดิมเริ่มเป็น 9:16 ส่วนลิงก์ชนิดอื่นเริ่มเป็น 16:9 และแก้จากแอดมินได้ ใช้ `php artisan content:install` เมื่อติดตั้งหรืออัปเดต

หน้าโปรเจกต์สลับคอนโด/วิลล่าด้วยแท็บ เมื่อกด New Projects หรือลิงก์วิดีโอ ระบบเปิดหมวดของโครงการนั้นและเลื่อนไปที่รายละเอียดให้เอง การ์ด New Projects แสดงเฉพาะรูป ชื่อ และทำเล ป้าย NEW ใช้ริบบิ้นแดง ส่วนโครงการแนะนำใช้ดาวทอง

ในหน้าแก้โปรเจกต์ ลากรูปได้ด้วยเมาส์ หรือใช้ปุ่มลูกศรและ “ตั้งเป็นปก” บนมือถือ เลือกรูปใหม่ได้หลายครั้งต่อเนื่อง และสลับเข้ากับรูปเดิมได้ก่อนบันทึก การนำรูปออกในหน้าฟอร์มจะมีผลเมื่อกดบันทึกเท่านั้น

## Leads และแดชบอร์ดลูกค้า

- เมนู **Leads / ลูกค้า** แสดงคำขอที่ส่งผ่านฟอร์มบนเว็บ ค้นหาชื่อ เบอร์ อีเมล โครงการ และผู้ดูแลได้ พร้อมกรองวันที่ สถานะ ภาษา และแหล่งที่มา
- เปิดรายการเพื่อปรับสถานะ ใส่ชื่อเซลส์ บันทึกผลติดต่อ และนัดติดตามครั้งถัดไป ใช้เวลาประเทศไทย
- **แดชบอร์ดลูกค้า** ดู 7/30/90 วันล่าสุด: คำขอรายวัน เบอร์ไม่ซ้ำ คำขอซ้ำ สถานะ โครงการ แคมเปญ และภาษาที่ใช้ส่งฟอร์ม
- หนึ่ง Lead คือหนึ่งคำขอ เบอร์เดียวกันอาจส่งหลายครั้ง ระบบไม่รวมรายการให้อัตโนมัติ
- โครงการ ภาษา และ UTM ของข้อมูลเดิมไม่สามารถสร้างย้อนหลังจากชื่อหรือเบอร์ได้ จะแสดงว่าไม่ระบุ และเริ่มบันทึกจากฟอร์มเวอร์ชันนี้
- ใช้ลิงก์เช่น `/ru?utm_source=facebook&utm_medium=paid&utm_campaign=phuket` เพื่อเริ่มเก็บแคมเปญ
- ดาวน์โหลด CSV จะใช้ตัวกรองปัจจุบัน ไฟล์มีข้อมูลลูกค้า ควรเก็บในที่ที่ผู้เกี่ยวข้องเท่านั้นเข้าถึงได้
- ผู้ดูแลเว็บไซต์ทุกบัญชีเข้าถึง Leads ได้ การสร้าง/เปลี่ยนสิทธิ์/ตั้งรหัสให้ผู้ดูแลคนอื่นต้องยืนยันรหัสผ่านของบัญชีที่กำลังใช้งาน

รูปแบบมือถือ: New Projects และวิดีโอเป็นการ์ดเลื่อนซ้ายขวาพร้อมเห็นการ์ดถัดไป คลิกวิดีโอจะเปิดผู้เล่นตามสัดส่วนเดิม YouTube ใช้ภาพหน้าปกคลิปจริงได้โดยอัตโนมัติ และแอดมินอัปโหลดปกเองได้สำหรับ Vimeo หรือเปลี่ยนปก YouTube

การเก็บเวลายังคงใช้ `config/app.php` เขตเวลาเดิมของเว็บไซต์ (`Asia/Bangkok`) เพื่อรักษาความหมายของเวลาในฐานข้อมูลเดิม อย่าเปลี่ยน timezone ของฐานข้อมูล/แอปโดยไม่วางแผนแปลงข้อมูลก่อน
